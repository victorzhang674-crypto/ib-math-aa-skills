# IB Mathematics AA Paper 1

The first-assessment-2021 format has compulsory short responses in Section A and compulsory extended responses in Section B. Each section is about half the marks. A clean AA formula booklet is available. Calculators are prohibited.

| Level | Time | Raw marks | Course weight |
| --- | --- | --- | --- |
| SL | 90 minutes | 80 | 40% |
| HL | 120 minutes | 110 | 30% |

For an exam session from May 2029 onward, verify the applicable format and syllabus before grading or generating a mock. [IB curriculum update](https://www.ibo.org/university-admission/latest-curriculum-updates/dp-mathematics-analysis-and-approaches-updates/)

## Mark a response

1. Match the paper and mark scheme by level, session, version or time zone, and question number. Get the complete question, diagram and legible student working. If the scheme is missing, independently solve the question and give a clearly labeled **practice estimate** with an explicit point breakdown. If a question or response is missing or unreadable, report the confirmed subtotal and identify the parts that need evidence. Score blank answers as zero only if the user confirms they were left blank or that the script is complete.
2. Mark by subpart against the matched scheme, including its examiner instructions. M credits method, A accuracy or an answer, and R reasoning. AG flags a result supplied in the prompt. A can depend on M. Bracketed marks may be implied by later work as the scheme permits. Keep multi-mark blocks together unless the scheme allows splitting. Credit equivalent expressions and valid alternative methods within the question's constraints. Apply follow-through (FT), misread (MR), accuracy, and any dependencies only as the matched scheme directs.
3. Trace the written algebra, substitutions, conditions, and logic. A correct value alone does not establish a required derivation. For “show that,” trace a derivation to the given result. For “prove,” check all logical steps and cases. For “hence,” check the link to the preceding result. “Hence or otherwise” allows another valid route. Check exactness, domain, extraneous roots and any requested units or precision. Distinguish a valid hand method with an arithmetic slip from a shortcut that requires a calculator.
4. Return a ledger with **part | marks earned/available | evidence and missing step**. Total the assessed parts, then give the highest-priority corrections with an example of the working to practise. Report a full-paper score only for a complete script. Use session-specific boundaries if the user asks for a grade estimate.

## Write solutions, practice questions, or plans

- For a worked solution, choose a reproducible by-hand route. Show the formula or key inference, intermediate algebra, and a final value in the requested form. Preserve exact values through the derivation when appropriate. Use readable numbers and manageable expressions when writing original questions.
- For a practice set, label it unofficial and check each item against the requested level. Mix short items across syllabus topics, and build each extended item around one mathematical theme with progressively more demanding parts. Solve every item by hand before delivering it. Include point allocations and alternatives for likely valid routes.
- For a study plan, group lost marks by topic and cause, such as wrong method, algebra slip or missing justification. Pair each priority with a drill, a timed set and an unassisted retry. For a mock, reserve review time and budget the rest by the marks on the paper.

Original marking illustration. For a 3-mark practice item asking students to solve \(\log_2(x-1)=3\) exactly and justify that the solution is admissible, award a method point for converting to \(x-1=2^3\), an accuracy point for \(x=9\), and a reasoning point for establishing \(x>1\) and checking that the solution satisfies this condition.
